One Skill Does Not Fit All: Automatic Discovery and Taxonomy-Guided Routing of Frame-Selection Skills for Long-Video Question Answering Jian Hu*1, Zixu Cheng*1, Da Li2, Wei Li3, Ziquan Liu1, Shaogang Gong1 1Queen Mary University of London 2Samsung AI Research Institute 3Nanyang Technological University, Singapore *Equal contribution · arXiv:2609.12517 · 2026 Paper Code Data AutoSkill method overview, three stages: (1) Execution-Guided Skill Discovery — an agent proposes, implements, evaluates, and refines skills against a 300-sample development set to build a Top-K skill toolbox; (2) Target-Adaptive Skill Routing — target-style domain adaptation and a question taxonomy are used to build an accuracy matrix and a category-to-skill routing table; (3) Category-to-Skill Inference — a test question is assigned a category, its routed skill selects frames, and the frozen backbone answers. AutoSkill discovers a toolbox of training-free frame-selection skills with LLM agents, then routes each question to the skill best suited to its semantic category — using only unlabelled target-side question/option text, never target videos or answers. Abstract Long-Video Question Answering (LVQA) requires locating decisive evidence in hour-scale videos under a limited frame budget. Most training-free methods apply the same frame-selection strategy to all questions, despite substantial variation in the evidence required by different question types. Our analysis shows that the relative effectiveness of frame-selection strategies varies across semantic categories and benchmarks, motivating adaptive evidence acquisition. In this paper, we introduce AutoSkill, a source-supervised framework for automatically discovering and routing executable frame-selection skills. Starting from a small labelled source pool, LLM agents iteratively propose, implement, evaluate, and refine candidate skills. For a target benchmark, AutoSkill uses only unlabelled question and option text to induce a shared semantic taxonomy, rewrite labelled source examples into the target style, and estimate a category-to-skill mapping. Neither target videos nor target answers are used in this process. At inference time, each question is assigned one skill, which selects the frames used in a single inference of the frozen video MLLM. Across five long-video benchmark splits, AutoSkill improves Qwen2.5-VL-7B and Qwen3.5-4B by 2.4% and 1.2%, respectively, demonstrating the effectiveness of our AutoSkill. Data The skill-discovery loop's development data is released on the Hugging Face Hub: Cade921/AutoSkill_dev. It contains dev300.json (the 300-sample development set that drives every discovery-loop cycle) and pool3000.json (the larger labelled source pool dev300.json was sampled from). The set is compiled from five public video-QA sources (VideoVista, ALLVB, LLaVA-Video-178K, SpaceR-151k, longvideo-reason); no video files are redistributed, and the dataset card lists per-source licenses and attribution.
